# markowitz-portfolio-optimization
script and dataset for Markowitz Portfolio Optimization - Bachelor's Thesis in Economics and Management.
Questa repository contiene il codice sorgente in R e il dataset storico utilizzati per il Capitolo 3 della tesi di laurea. Lo script esegue una simulazione Monte Carlo per calcolare la Frontiera Efficiente di Markowitz su un set di 15 fondi Eurizon, estraendo il portafoglio ottimale con il massimo Indice di Sharpe.
I dati storici (NAV giornalieri) contenuti nel file CSV sono stati estratti tramite database LSEG Workspace.
